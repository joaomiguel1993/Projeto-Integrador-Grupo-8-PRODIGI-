# SIGUI IA Service - Installation Guide

1. Criar e ativar venv (opcional)
   python -m venv venv
   source venv/bin/activate  (Linux/macOS)
   venv\Scripts\activate     (Windows)

2. Instalar dependências
   pip install -r requirements.txt

3. Configurar variáveis de ambiente (exemplos)
   export SIGUI_DB_URL=postgresql+psycopg2://user:pass@host:5432/sigui_db
   export MODELO_TRIAGEM_PATH=models/xgboost_triagem.joblib
   export ENCODERS_TRIAGEM_PATH=data/processed/encoders_triagem.joblib
   ...

4. Correr serviço
   uvicorn main_ai:app --reload --port 8000

5. Aceder à documentação Swagger
   http://localhost:8000/docs
