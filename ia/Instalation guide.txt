# Configurar o Groq API (gratuito, sem instalação local):
#   1. Aceder a https://console.groq.com
#   2. Criar conta (se ainda não tiveres)
#   3. Clicar em "API Keys" -> "Create API Key" e copiar a chave gerada
#   4. Adicionar a chave ao ficheiro .env na raiz do projeto:
#      GROQ_API_KEY=gsk_...

# Para correr localmente (teste)
#   5. Antes de correr o voz_nlp.py, definir a variável no terminal:
#      Git Bash:   export GROQ_API_KEY="gsk_..."
#      PowerShell: $env:GROQ_API_KEY="gsk_..."
